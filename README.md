# ひまつぶし工房

広告なし・課金なしで遊べるミニゲーム集です。ホーム画面に追加すると、アプリのように開けます（一度開いたゲームは通信なしでも遊べます）。

**遊ぶ:** <https://seg1gpt0jpn.github.io/nejihodoki/>

| ゲーム | フォルダ | 内容 |
| --- | --- | --- |
| ネジほどき 3D | `neji/` | 模型を回して隠れたネジを探し、同じ色の箱へ集める立体パズル |
| ブロックはめ | `blocks/` | 8×8の盤にブロックをはめて列を消すパズル |
| おちものタワー | `drop/` | 落ちてくるブロックで列をそろえる落ちものパズル |
| いかだ暮らし | `raft/` | 漂流物を拾ってイカダを広げる海上サバイバル |
| ゲートランナー | `gates/` | 数字のゲートで仲間を増やして敵を倒すアクション |
| ころがし工房ゴルフ | `minigolf/` | 作業台の上のミニゴルフ。引っぱって打つ3コース27ホール（練習・今日のホールつき） |

どれも、元になった人気ゲームの名前・絵・ステージは使わず、同じジャンルの遊び方を一から作ったものです。

共通のファイル：トップページ `index.html`、アプリの設定 `manifest.webmanifest`、オフライン用 `sw.js`、アイコン、Firebase の設定 `firebase-config.js`。

## ネジほどき 3D

立体の模型を回して、隠れたネジを探し、同じ色の箱へ集めていく3Dネジ外しパズルです。
広告・課金はありません。

**遊ぶ:** <https://seg1gpt0jpn.github.io/nejihodoki/neji/>

### 遊び方

- 模型をドラッグで回します（下からも見られます）。ピンチやホイールで拡大できます。
- ネジの頭の先に別の部品があるネジは抜けません。手前の部品から外していきます。
- 抜いたネジは同じ色の箱に入ります。合う箱がないときは予備スロットに置かれます。
- 予備スロットが埋まり、どの箱にも入れられるネジがなくなったら失敗です。
- 黒い輪の鍵つきネジは、金の印のネジを抜くまで抜けません。
- 「のぞく」を押している間は、いちばん外側の部品が透けて一段奥が見えます。

### しくみ

- `neji/index.html` の1ファイルで動きます。3D表示に Three.js（cdnjs から読み込み）を使っています。
- 問題は自動で作ります。作るときに、雑に抜くプレイヤーを何十回も試して高い確率で負ける色の並びを選びます。そのうえで、解答探索で解けることを確かめ、解答手順も保存します。
- 難易度は、雑なプレイの失敗率と必要な予備スロット数から実測して、入門〜最高難度の7段階で表示します。
- 進み具合はブラウザに保存されます。メニューの引き継ぎコードで別の端末に移せます。
- Googleログイン（Firebase）による同期は、`firebase-config.js` に設定を入れると使えるようになります。手順は [FIREBASE_SETUP.md](FIREBASE_SETUP.md) を見てください。
