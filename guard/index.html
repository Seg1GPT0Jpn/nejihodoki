ひまつぶしガード（Android）

自分で決めた「使いすぎのルール」を守るための、Android 用の自己管理アプリです。アプリごとの 1 日の上限、学校・おやすみなどのブロック時間帯、クイズで少しだけ解除、集中モード、使用時間のグラフ、をひとつにまとめました。広告なし・アクセス解析なし・通信なし（ネットに接続する権限そのものを持っていません）。データはすべて端末の中にあります。

ご注意：これは「自分の意思を助ける道具」です。ほかの人（保護者など）が決めた制限を回避する仕組みはありません。また、使う人が本気で外そうとすれば外せます（下の「できないこと」）。インストールは自己責任でお願いします。

ダウンロード

APK をダウンロード（最新版） ビルドの一覧（Actions）

ファイル名：himatsubushi-guard.apk（デバッグ署名）。「最新版」は main に変更が入るたびに GitHub Actions が自動でビルドし直します。上のリンクが開けないときは、「ビルドの一覧」から最新の実行を開き、himatsubushi-guard-apk（zip）をダウンロードして中の APK を使ってください（GitHub へのログインが必要です）。

できること

  • アプリごとの 1 日の上限と、曜日・時刻のブロック時間帯（日またぎ可。例：金曜 22:00〜翌 6:00）。インストール済みのアプリから選びます。
  • 制限に当たると全画面のロック画面：解除までのカウントダウン、クイズで解除（3〜10 問。正解で 5〜30 分。まちがえると時間が減り、次の挑戦まで待ちます）、PIN と理由つきの緊急解除（5 分）。
  • クイズは内蔵の自作問題（算数・数学／漢字（小 1〜中 3）／英語／社会／理科 あわせて 800 問以上）と、自分の CSV・JSON の取りこみ。
  • 集中モード（15・25・45 分）：選んだアプリを使えなくし、通知に残り時間を表示します。
  • 使用状況：今日と 7 日のグラフ、上限内だった日の連続日数、週のまとめ。
  • PIN（ソルトつきハッシュで保存）、設定の書き出し・読み込み、明るい／暗いテーマ、日本語／英語。

衝動的なすり抜けに強くする工夫

  • 待ち時間（初期 10 分）：上限を増やす・時間帯を縮める・アプリを外す・保護をオフにする、などの「ゆるめる変更」は、待ち時間のあとに反映されます（取りやめ可）。きびしくする変更はすぐです。
  • コミットメント：選んだ日数（3〜30 日）、ゆるめる変更を一切できなくします。緊急解除は回数・間隔の制限つきで使えます。
  • 時計を変えても増えない：使える時間は端末の時計ではなく起動からの経過時間で数えます。時計の巻き戻し・タイムゾーンの変更は検知して記録します。
  • 権限が外されたら：検知して記録し、ほかのアプリを開くたびに「権限を戻す」画面を出します。起動時・アプリ更新時の自動再開、見回りの再起動にも対応。
  • 設定ページの保護：ブロック時間帯かコミットメントのあいだ、設定アプリの「このアプリの情報」「ユーザー補助」「使用状況へのアクセス」「デバイス管理アプリ」「日付と時刻」とアンインストール画面を開けなくします（ユーザー補助が必要）。
  • 端末管理者（任意）：設定から直接アンインストールしにくくします。解除には PIN と待ち時間が必要です。
  • 正直レポート：過去 7 日の「すり抜けの疑い」と緊急解除（理由つき）をそのまま見られます。

必要な権限と、その理由

権限理由
使用状況へのアクセス（必須）どのアプリをどれだけ使ったかを知るため。
他のアプリの上に表示（必須）制限に当たったとき、ロック画面を前面に出すため。
通知見守り中・集中モードの残り時間の通知のため。
電池の最適化の除外省電力機能で見守りが止まらないようにするため。
ユーザー補助（任意・おすすめ）アプリの切り替えをすぐ検知／保護する設定ページの見分け。画面の文字は保存・送信しません。
端末管理者（任意）アンインストールしにくくするため。ロックや消去などの権限は要求しません。
起動時の実行再起動のあとに見守りを再開するため。

インターネット接続の権限（INTERNET）はありません。

インストール方法（Pixel などの Android）

  1. この端末の Chrome で、上の「APK をダウンロード」を開き、ダウンロードします。「このタイプのファイルは端末に問題を起こす可能性があります」と出たら、内容を確認して「ダウンロード」を選びます。
  2. ダウンロードが終わったら、通知かファイルアプリから himatsubushi-guard.apk を開きます。
  3. 「不明なアプリのインストール」の許可を聞かれたら、「設定」を押し、Chrome（またはファイル）を「許可」にして戻ります。（Pixel：設定 → アプリ → 特別なアプリアクセス → 不明なアプリのインストール）
  4. 「インストール」を押します。「Play プロテクト」が確認を出したら、自分でビルドさせたアプリであることを確かめて「インストールする」を選びます。
  5. インストール後は、不明なアプリのインストールの許可を「許可しない」に戻すと安心です。
  6. アプリを開き、画面の案内に従って権限を 1 つずつ許可します（案内に、設定画面へのボタンがあります）。
ユーザー補助が押せないとき（Android 13 以降）
アプリを直接インストールすると、ユーザー補助がグレーで押せません。アプリの「アプリ情報」を開き、右上の「︙」→「制限付き設定を許可」を選んでから、もう一度ユーザー補助を開いてください。
更新するとき
配布している APK はデバッグ署名で、ビルドのたびに署名が変わることがあります。署名が違うと、上書きインストールできないことがあります（その場合は、端末管理者を解除してからアンインストール → 再インストールになります。設定は先に書き出しておいてください）。

できないこと（限界）

  • 端末の安全モードでの起動、ADB、初期化、ほかの方法でのアンインストールは止められません。
  • 「使用状況へのアクセス」や「ユーザー補助」は、端末の設定から外せます。外されたことは検知・記録して復旧画面を出しますが、ホームボタンまでは止められません。
  • 設定ページの保護は、画面の見出しの文字で見分けます。端末・言語・Android のバージョンによっては効かないことがあります。
  • メーカー独自の省電力機能（一部の機種）で、常駐が止まることがあります。案内に従って電池の最適化を外し、メーカーの設定も確認してください。
  • ほかの人が決めた制限（Family Link など）を回避する機能はありません。

プライバシー

  • データ（設定・使用時間・記録・PIN のハッシュ）は、この端末の中だけに保存されます。外部へ送りません（通信の権限がありません）。
  • 広告・アクセス解析・クラッシュ送信・Google Play 開発者サービスは使っていません。
  • 端末のバックアップにも含めない設定にしています（アプリを消すとデータも消えます）。設定のファイル書き出しは、自分の操作でだけ行います。
  • アプリのコードはこのリポジトリの android-guard/ にあります。

Himatsubushi Guard (Android)

A self-control app for Android that helps you keep limits you set for yourself: daily limits per app, blocked windows (school hours, bedtime), a quiz to earn a little time back, focus mode, and usage charts. No ads, no analytics, no network (the app does not even hold the internet permission). Everything stays on your phone.

Please note: this is a tool to support your own will. It has no way to bypass limits set by someone else (a guardian, Family Link…). A determined user can still remove it (see "What it cannot do"). Install at your own risk.

Download

Download the APK (latest) Build list (Actions)

File name: himatsubushi-guard.apk (debug-signed). GitHub Actions rebuilds it whenever the app changes on main. If the link does not open, open the latest run in "Build list" and download the himatsubushi-guard-apk artifact (zip) — a GitHub sign-in is required.

What it does

  • Daily limits per app and weekday/time blocked windows (overnight windows supported, e.g. Fri 22:00 – Sat 6:00), chosen from your installed apps.
  • A full-screen lock screen when a limit is hit: countdown to unlock, unlock with a quiz (3–10 questions, 5–30 min earned; wrong answers cost time and add a wait), and a PIN-protected 5-minute emergency unlock with a logged reason.
  • Quizzes come from original built-in questions (math, kanji grades 1–9, English, social studies, science; 800+) and from your own CSV/JSON file.
  • Focus mode (15/25/45 min): blocks the apps you choose and shows the remaining time in a notification.
  • Usage: today and 7-day charts, a streak of days within limits, and a weekly summary.
  • PIN (stored as a salted hash), settings export/import, light/dark theme, Japanese/English.

Built to resist impulsive bypass

  • Waiting period (default 10 min): "loosening" changes (higher limit, shorter window, removing an app, turning protection off…) apply only after the wait (you can cancel). Tightening is instant.
  • Commitment mode: for 3–30 days no loosening change is possible at all. Emergency unlock still works, limited in count and spacing.
  • Changing the clock does not help: time is counted from uptime, not the clock. Clock rollbacks and time-zone changes are detected and logged.
  • If a permission is revoked: it is detected and logged, and a "restore permissions" screen appears whenever you open another app. The guard restarts after boot and after updates, plus a watchdog.
  • Protected Settings pages: during a blocked window or commitment mode, App info for this app, Accessibility, Usage access, Device admin apps, Date & time and the uninstall dialog cannot be opened (needs the accessibility service).
  • Device administrator (optional): makes uninstalling from Settings harder. Deactivating needs the PIN and the waiting period.
  • Honesty report: the last 7 days of tamper-like events and emergency unlocks (with reasons), shown plainly.

Installing on a Pixel (or other Android)

  1. On the phone, open "Download the APK" in Chrome and download it. If Chrome warns that this type of file can be harmful, check the source and choose "Download".
  2. When it finishes, open himatsubushi-guard.apk from the notification or the Files app.
  3. If asked about "Install unknown apps", tap "Settings", allow it for Chrome (or Files), and go back. (Pixel: Settings → Apps → Special app access → Install unknown apps.)
  4. Tap "Install". If Play Protect asks, confirm it is an app you built yourself and choose "Install anyway".
  5. Afterwards, turn "Install unknown apps" off again for that app.
  6. Open the app and follow the on-screen guide to grant each permission (it has buttons that open the right settings page).
If Accessibility is greyed out (Android 13+)
Sideloaded apps get "restricted settings". Open the app's App info, tap ⋮ at the top right, choose "Allow restricted settings", then open Accessibility again.
Updating
The distributed APK is debug-signed and the signature may change between builds. A different signature cannot be installed over the old app (you would deactivate the device administrator, uninstall and reinstall — export your settings first).

What it cannot do

  • It cannot stop Safe Mode, ADB, a factory reset, or other ways of uninstalling.
  • Usage access and Accessibility can be revoked in system settings. The app detects, logs and shows a restore screen, but cannot block the Home button.
  • Settings-page protection recognises pages by their title text, so it may not work on every device, language or Android version.
  • Some manufacturers' own battery managers may still stop background services; follow the guide and check the vendor settings too.
  • It has no feature to evade limits set by someone else (Family Link etc.).

Privacy

  • Data (settings, usage, logs, the PIN hash) is stored only on this device and is never sent anywhere (there is no network permission).
  • No ads, no analytics, no crash reporting, no Google Play services.
  • It is excluded from device backups (uninstalling deletes the data). Exporting settings happens only when you do it.
  • The source is in android-guard/ in this repository.
