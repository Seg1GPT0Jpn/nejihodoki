What we used (and nothing else; no sample from any other library is in this folder)
  Strings   violin / viola / cello sections and the solo contrabass (sustain with vibrato, spiccato, pizzicato), harp
  Winds     flute, oboe, clarinet, bassoon (sustain, staccato)
  Brass     F horn, trumpet, tenor trombone, tuba (sustain, staccato)
  Percussion timpani (5 drums), bass drum, suspended cymbal (VSCO 1 percussion, also in the VSCO 2 CE repository)
  The files here are derived works: mono, trimmed (2.8 s sustained notes with a loop region, 0.5 - 1.6 s short notes, 3 - 4 s for drums),
  loudness-normalised per note, MP3 (libmp3lame VBR q4). The recordings are not sold or offered as a sample library; they are part of this game.

How the bank was built (reproducible)
  git clone --filter=blob:none --no-checkout --depth 1 https://github.com/sgossner/VSCO-2-CE vsco
  cd vsco && git sparse-checkout init --no-cone && git sparse-checkout set <the folders listed at the top of tools/build-orchestra-samples.js> && git checkout
  node tools/build-orchestra-samples.js --src vsco
  (ffmpeg with libmp3lame is needed; the build is deterministic for the same ffmpeg build.)

Not used on purpose
  Philharmonia Orchestra samples (terms forbid offering the samples as such), Sonatina Symphonic Orchestra (retired CC Sampling Plus 1.0),
  Virtual Playing Orchestra (mixed ShareAlike content), WebAudioFont / GeneralUser GS style General MIDI banks (GPL / dated sound).
