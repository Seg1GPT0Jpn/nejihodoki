## 作り方（もう一度作る・ほかの街を足す）

```sh
OSM_CACHE=/path/to/cache node tools/osm-city.js            # 全部の街
OSM_CACHE=/path/to/cache node tools/osm-city.js kamiooka   # 1つだけ
OSM_CACHE=/path/to/cache node tools/osm-city.js kyoto --dump  # 名前のある物の位置（<cache>/kyoto-names.json、目印を置くとき用）
node tools/osm-city.js --list                              # 街の一覧（中心の緯度経度と範囲）
```

- `tools/osm-city.js` の `CITIES` に、街の id・名前・中心（緯度・経度）・半径 `R`（m）か範囲 `box` を書きます。高さを直したい建物は `fix` で上書きできます。
  - 建物の多い都心は `tile`（取りに行く1枚の大きさ、度）を小さくします。OpenStreetMap API が「点が多すぎる」と断った範囲は、自動で4つに分けて取り直します。
  - `simp`（建物の輪郭を まとめる許容 m）と `minA`（これより小さい建物は入れない m²）で、ファイルの大きさを決めます（gzip で 220 KB くらいまで）。
  - `lite: 1`：外まで続く大きな面（川の水面など）の足りない線を取りに行き、名前のしぼり込みを強くします。
- 元データ（OpenStreetMap API の `/map` タイル、標高タイル）は `OSM_CACHE` の場所に保存し、2回目からはそれを使います。`--refetch` で取り直します。Overpass は使いません（よく 504 になるため）。
- 海は、海岸線（`natural=coastline`、陸が左・海が右）をつないで範囲で切り、範囲のふちを時計まわりにたどって 海の面を作ります。範囲の中の島は `ar` の種類 19（陸）で、ページは海の面の穴として扱います。
- できたファイルをページで使うには、`hole/cities.js` に街の定義（`data: 'cities/<id>.json'`、`real: { areas, start, lm, trains … }`）を書きます。
  - `real.drop`：その点を含む地図の建物を消す（手づくりの模型と入れかえる）。`real.extra` の中の `h.lmk(型, [x, z], { yaw, rot, x, z })` で、その建物の場所・向きに模型を置きます。遊ぶ範囲の外の模型は 景色だけ（のみこめず、合計にも入りません）。
  - `real.paint`：`[x, z, 壁の色, 屋根の色]` その点の建物の色（赤レンガ倉庫など）。`real.bridges`：`[x, z, 色, 半径]` その近くの橋の欄干の色。
  - `real.deco(G)`：地面に足す絵（スクランブル交差点の斜めの横断歩道など）。`real.labels`：ながめるモードの名前。

## ファイルの形（v1）

座標は中心からの東向き（x）と南向き（z）のメートルを `q`（0.5 m）単位の整数にしたもので、点の列は差分で書いてあります。

| キー | 中身 |
| --- | --- |
| `b` | 建物 `[種類, 高さdm, 下端の高さdm, フラグ, 点の数, x0, z0, dx, dz, …]`（フラグ 1 = 屋根だけ、8 = ドーム） |
| `rd` | 道 `[種類, 幅dm, 高架, 点の数, …]` |
| `rl` | 線路 `[種類, 高さ(-1 地下 / 0 地上 / 1 高架), 会社, 点の数, …]`（会社の番号は `tools/osm-city.js` の `opOf`） |
| `ar` | 面（公園・水・学校・駐車場・ホーム・デッキなど）`[種類, 点の数, …]`（19 = 海の中の島） |
| `wl` | 川・水路 `[幅dm, 点の数, …]` |
| `tr` | 木 `[x, z, …]` |
| `lb` | 名前 `[[名前, x, z, 種類]]`（種類：station / school / river / bridge / public / park / shrine / stationb） |
| `en` | 点（地下鉄の入口・バス停・信号・横断歩道）`[[x, z, 種類, 向き, 幅dm]]` |
| `hg` | 標高（20 m ごとの格子、dm、行ごとの差分） |

ファイルの形や街の作り方（物の数や順番）を変えたら、`hole/cities.js` の街の `v` を上げます（オンライン対戦は、全員のページが同じ `v` の街だけを選びます）。まちめぐりの10都市は 手づくりの街（v なし = 0）から地図データ（`v: 1`）になりました。
